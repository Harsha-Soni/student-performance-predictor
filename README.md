#  Student Performance Predictor

A Machine Learning web application that predicts student scores based on:

- Weekly Self Study Hours
- Attendance Percentage
- Class Participation

# Tech Stack

- Python
- Pandas
- Scikit-Learn
- Streamlit

# Model

- Linear Regression
- R² Score: 0.66

# Features

- Interactive UI
- Real-time score prediction
- Performance feedback

# Run Locally

pip install -r requirements.txt

streamlit run app.py
